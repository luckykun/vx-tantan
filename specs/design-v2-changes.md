## 二、规则细化（讨论轮确认）

1. **弹药模型**：每关 **3 颗球 = 3 次发射机会**。发射第 1 颗后可**立即发射下一颗**（允许同屏多波球），也可等球全部漏完再发。
2. **回弹规则**：接住 = 沿**横条当时的拖动方向**弹出（拖动速度注入横向分量），不是镜面反射、也不是按接球点偏移。静止接住则近似原路竖直回弹。
3. **球的唯一结局**：没接住、越过漏接线 → 该球永久消失。**接住不再消耗球**。
4. **胜负**：
   - 胜：方块全消（即时判定，不等球落完）。
   - 败：3 次发射机会用完 **且** 同屏球全部漏完，方块仍有剩余。
5. **星级**：通关耗时 ≤ `starTimes[0]` → 3 星；≤ `starTimes[1]` → 2 星；否则 1 星。时间线以 v2 仿真数据校准（熟练玩家中位耗时 ≈ 三星线，新手中位 ≈ 二星线）。
6. 原 §1 确认的「接住转弹药 / 回合结算保底 1 球」机制**整体作废**。

## 三、尺寸规范重推导（§4 重写依据）

30 列不是可自由凑整的参数，整条推导链如下（基准分辨率 375×667，运行时按设备宽度等比缩放，**375 只是设计基准不是目标机型**）：

| 参数 | v1 | v2 | 说明 |
|---|---|---|---|
| COLS | 9 | **30** | 需求方指定 |
| PAD（左右留白） | 12 | 12 | 不变 |
| CELL | 39 | **11.7** = (375−24)/30 | 小数逻辑像素，Canvas 直接支持 |
| ROWS | 10 | **22** | 竞技区高 257.4px |
| ARENA_BOTTOM | 511 | **337.4** | 接球区增大到 262px，容纳更多落球反应 |
| BALL_R | 8 | **5.5** | 球径 ≈ 0.94 格，与格宽同量级 |
| 缺口宽度 | 3 格(117px) | **L1 12格 / L2 10格 / L3 8格** | 绝对宽度 140.4/117/93.6px |
| 入射角容差 | ±22° | **±14.0° / ±11.5° / ±8.9°** | atan((缺口半宽−球径−1) / 发射点到缺口距离 256.1px) |
| BALL_SPEED | 430 | **420** | 配平实测：300 px/s 下清屏吞吐不足，单局>5min；提速后胜局均耗时 54~123s |
| PADDLE_W | 92 | **64** | 相对屏宽变窄，配合耗时评星控制漏接张力 |
| 方块总数（3 关） | 26/37/49 | **101 / 167 / 212**（全高度散布 scatter） | 需求方要求“很多才有意思”；配平结论：连续顶棚清屏太慢，散布才能让球全程有块可打 |
| STALL_TIME | 回合 14s | **22s 无消除** | 配平实测：10s 会在稀疏残局过早排空活球，22s 通关率近乎翻倍 |
| LEVEL_TIMEOUT | （无） | **240s 硬超时强制开底** | 收敛兜底：残局单球大场地往返，两次消除间隔可永远 < STALL_TIME，停滞计时无法单独收敛（仿真撞到过） |

## 四、结构性影响（连带作废的内容）

- **§3 核心闭环**：回合制（发射→逸出→接球→结算）改为**连续弹道制**（发射→消除→逸出→接住回弹→…→漏完），「接住几颗=下次连射几颗」弹药语义删除。
- **§7 状态机**：`AIM/FLY` 互斥改为 `PLAY` 单态内瞄准/摆位/回弹并行（拖空白=瞄准可随时进行，包括球飞行中）。
- **§8.4 超时开底**：语义从"回合 14s 超时"改为"**停滞 10s**（连续无消除）开底排空当前球"，开底期间接住**不再回弹**（保证必然收敛，同时是对磨洋工的惩罚）。
- **§10 计分**：删除「剩余次数折算分」；星级改耗时；接住 +5 保留（改为回弹奖励）。
- **§11 整套配平**：v1 数据全部作废（回合制 + 9 列前提下产出），需以 v2 模型重跑仿真并重新校准 `starTimes`；v1 方法论（§11.1 工具自证、§11.5 调优记录）保留存档。
- **§15 埋点**：`shotOriginDrift` 议题自然消解（不再有下一轮弹药原点概念）；新增 `bounceChain`（单次发射的回弹连击长度）与 `stallOpen`（停滞开底触发）。
- **§16.1 待拍板问题**：Q2（接球要不要）已被本文第 2 条取代；Q4（超时开底）保留但语义改停滞开底；Q5（保底补 1 球）作废。
- **连射 VOLLEY_GAP / heldBalls / spawnQueue**：整体删除。
