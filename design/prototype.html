操作方式（v2）

  1. 瞄准：在空白处按住并移动 → 只显真实弹道预测点列（已按要求去掉挡板→手指的虚线）。青色 = 能命中可消方块；红色 + ✕ = 预测内撞不到任何方块（等于空放）。
  2. 发射：瞄准后松手即射出，消耗 1 次发射机会；每关共 3 颗球 = 3 次机会，可不等落地马上连发。
  3. 接球回弹：球落回时按住横条拖动 → 接住后球朝你拖动的方向继续弹回去（不再变成弹药），回弹链可以无限延续。
  4. 胜负：方块全消即胜（按耗时评 1~3 星）；3 次机会用完且场上球全部漏完即败；连续 22s 无消除或关卡超 240s 会开底排空。
  5. 也可用下方 ◀ ▶ 按钮微调挡板。
  6. 钻石钱包（v5 需求①）：每次结束按获得星数 +N 颗钻石（1 星 = 1 钻），写入本地钱包，持久化。
  7. 主动道具栏（v5 需求②）：横条下方三个按钮—全部分裂/墙体隐藏/挡板放大，显示持有数量。数量 > 0 点击立即使用一次；为 0 点击弹窗引导购买（分裂 2 钻、墙体隐藏 1 钻、挡板放大 1 钻）。
  8. 暂停（v5 需求③）：右上角 ⏸ 按钮 → 弹窗可选「继续游戏 / 回到主页 / 关闭声音」；主页点「开始游戏」重新开局。

原型已实现的规则（v7）

① 双区物理：竞技区无重力匀速镜面反弹（弹道可 100% 预测）；接球区匀速直线 + 挡板拦截。
② 30 列×22 行网格（需求拍板）：单块 11.7px@375 基准，单关可消方块 101~212 个。
③ 每关 3 颗球 = 3 次发射机会，可立即连发；接住不回收弹药，而是沿横条拖动方向直接回弹（拖动速度注入 ±78° 限角）。
④ 胜 = 方块全消；败 = 3 次机会用完且场上球全部漏完；球落到滑轨轨道（横条外）即判漏接，永久消失。
⑤ 星级按通关耗时评定（HUD 实时耗时，开场自动计时）；废弃「剩余次数比例」评星。
⑥ 收敛保障：仅保留关卡硬超时 180s → 开底排空（v3 已移除停滞倒计时；开底期间接住不再回弹）。
⑦ 子步进 8 次 + 最近点法线求解，杜绝高速穿透（900px/s 压测 0 异常）；分裂冷却 0.12s + 同屏 16 球上限。
⑧ 瞄准反馈：已按要求删除瞄准虚线，只保留渐隐弹道预测点列 + 首命中圈。
⑨ 进度/星级写入 localStorage；配平门禁：node design/balance-sim.js + seed-check.js 退出码 0。
⑩ 道具方块消除即生效：消除道具块后直接在原坐标发挥效果，不再掉落悬浮块。占比固定为可消除方块的 6%（v7 需求④），加权：分裂二球1成·分裂三球3成·爆炸1成·生命1成·横条加强3成·隐形1成（快速球不再随机投放）；方块区无墙壁时不投放隐形（v7 需求①）。道具消除时的提示文字改为在原方块位置弹出（v7 需求②）。
⑪ 钻石钱包（v5 需求①）：每次结束按获得星数补发钻石（1 星 = 1 钻）并本地持久化，主页 / 结算 / 道具栏上方均显示余额。
⑫ 主动道具栏（v5 需求②）：横条下方「全部分裂 / 墙体隐藏 / 挡板放大」，持有数量 >0 点击直接生效、=0 点击弹购买窗（分裂 2 钻、其余各 1 钻）。
⑬ 主页与暂停（v5 需求③）：右上角暂停 →「继续游戏 / 回到主页 / 开关声音」；启动先进主页，点「开始游戏」进关。
⑭ 仅方块区抖动（v6 需求1）：命中/爆炸的屏幕抖动只作用于方块区（竞技区框+方块），背景/HUD/挡板/道具栏不再整屏晃动。
⑮ 挡板中心倒计时（v6 需求2 / v7 需求①）：挡板变宽时长 30s，触发时倒计时改显示在横条中间上方（跟随横条中心，数字轻微抖动，末 3s 变红闪烁）。
⑯ 提示统一（v6 需求3）：所有居中浮动提示统一白色同字号文字、依次向上堆叠，每条 1.5s 后消失（最多 4 条 FIFO）。
⑰ 球速调整（v6 需求4 / v7 需求④）：小球进入方块区速度 500px/s，方块区下方(接球区) 420px/s（CATCH_SPEED_K=0.84，逸出即减速留反应时间）。
⑱ 收窄缺口（v6 需求5）：每关底部墙体缺口连续 EMPTY 段按 GAP_MAX_CELLS=5 居中裁剪回墙壁，缝隙不再过大（L1 由 12 格→5 格，入射容差 ±24°→±9°）。
⑲ 形状垂直居中（v7 需求②）：关卡装载时按内容行包围盒在方块容器内垂直居中（recenterMap），底部墙壁行固定不动，解决原设计「偏上」。
⑳ 道具方块统一底色（v7 需求③）：所有道具方块背景与普通方块一致（蓝紫渐变），仅靠图标区分——分裂=两白点、三分裂=三白点、爆炸=橙色炸弹、生命=白色爱心、挡板=绿色实心横条、快速=白色双箭头、隐形=白色幽灵。
㉑ 墙壁纯色（v7 需求⑤）：不可消除墙壁改为纯背景色填充，去掉原两个铆钉白点。
