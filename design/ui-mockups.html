界面视觉稿

本文档给出 10 个界面的高保真稿与组件、动效、资源规范。稿子用 HTML/CSS 构建而非图片， 好处是配色字号可直接复制、开发者能当样式基线用，改起来不用重画。 下方手机模型均按 242 × 430 等比呈现（真实逻辑分辨率 375 × 667）。

01视觉基调

定位关键词

暗底霓虹糖果质感高对比方块 发光小球克制的信息密度强反馈

整体走「深夜台球厅」路线：背景压到接近纯黑，让糖果色方块自己发光。 这样做的三个理由：① 方块是玩法核心，v4 需求①将可消除方块统一为单一天蓝（辨识靠形状/图标），暗底让方块与七类道具块的层级拉开到最高； ② 霓虹光晕天然适合表现「分裂」「入缺口」的高光时刻； ③ 省电且在 OLED 机型上观感最好。

反面参考（我们不做的）

✗ 明亮卡通风（大量白底 + 粗黑描边）：会让「墙壁 / 可消除方块」的层级关系糊在一起， 且与同类弹球产品高度雷同。
✗ 拟物 3D 方块：贴图成本高、包体大（主包 4MB 限制）、低端机 draw call 压力大。
✗ 满屏特效：方块数已达 49，若每块都带闪光，玩家无法快速读取「该打哪一块」。

唯一需要小心的点 暗底霓虹在户外强光下可读性差。方案：设置里提供「明亮主题」切换（P1）， 两套主题共用同一份方块色板，仅换背景与描边亮度。

4.2 游戏内元素

方块v2 网格 30 列 × 22 行，单元格 11.7px（对应逻辑坐标）；无缝衔接（inset 0）+ 2.2px 小圆角（v2.2：相邻圆角相拼呈纽扣状，可爱但不留缝隙），纵向渐变 + 顶部高光 + 0.5px 淡黑描边（仅保证视觉边界）；墙壁行同样处理
墙壁同尺寸，灰蓝 #5A608C→#33375A，1pt 白描边 12%；不加任何彩色以保证“打不掉”的读感
道具方块v4 共七种，均可消除且带发光（shadowBlur 8）；生效方式统一改为“掉落悬浮块”（需求④）：消除后并不立即生效，而是从原坐标垂直掉落一个降透明度的悬浮块（DROP_SPEED=150），需玩家用横条接住才在原坐标真正发挥道具作用（落到轨道即作废）。① 分裂块 S 青 #7CF6FF→#00B8D4 双叉，接住后原坐标一分为二；② 三分裂块 T 紫 #C77CFF→#8A2BE2 三叉（需求⑧）；③ 生命块 L 粉 #FF9ECF→#F0368B 白心形，剩余发射 +1；④ 爆炸块 X 橙 #FFB15A→#F0642B 星芒，原坐标清空 3×3；⑤ 挡板块 P 绿 #9BE86B→#3FAE2E 向上箭头，挡板满宽 20s（需求⑩，最后 3s 闪烁）；⑥ 快速球块 F 黄 #FFE07A→#F5A61E 双箭头，原坐标一颗双倍速球（需求⑧）；⑦ 隐形块 G 白蓝 #E6ECFF→#9AA6CC 虚线幽灵，方块区墙壁可穿 10s（底部墙行除外，需求⑨）。每关由 injectProps() 随机把 5%~10% 可消除块换为道具块（需求⑥）
小球直径 11px（BALL_R=5.5），径向高光偏左上 35%/30%，光晕 6px
横条v4 需求②：默认宽 120px（PADDLE_W=120，继续加宽让小球与道具悬浮块更容易接到）× 12px，圆角 6，金渐变 + 12pt 外发光；不再显示三颗待发射小球，剩余发射次数由顶部 HUD 圆点统一表达；接住时根据拖动方向施加 BOUNCE_KICK=0.55 的水平分量
缺口v4 需求⑦：不再统一宽度，每关自设缺口形式（宽窄/单双/左右/多小口）：L1 宽单口(12)·L2 对称双口(6+6)·L3 偶左单口(6)·L4 大小双口(3+8)·L5 偶右单口(8)·L6 两窄口(3+3)·L7 偶左单口(6)·L8 三小口(2+2+2)·L9 偶右单口(8)·L10 非对称双口(3+8)。缺口越多/越宽越易进出（难度低），单窄偏口最难；具体难度以 balance-sim 回测为准
方块颜色v4 需求①：可消除方块统一为单一天蓝色（#9DB0FF→#5566DE，PALETTE.bricks 仅 1 项），不再按坐标哈希循环取色；颜色不再携带任何语义，消除行为/得分与颜色无关。有含义的只有形状与图标：灰蓝铆钉块 = 不可消除墙壁；带发光图标的彩色块 = 七种道具（见上方「道具方块」，每种专属颜色）
滑动轨道v4 需求③：取消旧“漏接线”，改为横条下方一条 100% 竞技区宽的暗色同形轨道（rgba(255,255,255,.08) 圆角 + 端点刻度），视觉上像“滑轨”；球落到轨道平面（PADDLE_Y=DEATH_Y=487）且不在横条上时直接判漏接（悬浮道具块落轨同样作废）；横条与轨道整体上移，距方块区约 150px
剩余发射v2 统一 3 颗：用 实心圆点 而非数字（剩余 ● ● ●，已用 ○ 的透明度 28%），一眼看清，无需读数字；v2.1 后仅顶部 HUD 显示，挡板不再带球
顶部 HUDv3 四栏：关卡名 · 耗时（首次发射才计时）· 剩余发射圆点 · 消除进度。其中消除进度改为横向进度条（绿渐变 #7BEFC0→#22C58B + 百分比数字），取代旧纯文字
居中提示栏v4 需求⑤：接住悬浮块生效后，在方块区中央弹出浮层提示（如“生命 +1”“分裂 ×2”“墙壁隐形 10s”），颜色取对应道具主色；多条消息上下堆叠（最多 4 条），先显示的先消失（FIFO），带淡入/上浮/淡出动画
结算面板v3 星级仍按耗时评定（≤三星线 3★）；胜局展示总分明细：消除得分 + 剩余球×5 + 最大连击×10 + 耗时档（相对本关 starTimes 分 100/80/60/30 四档）；败局仅展示统计

4.3 HUD 三段式

高 72pt，三段固定：左 = 关卡名（认知锚点）、中 = 剩余发射（最关键资源，居中且用圆点）、 右 = 分数（等宽数字防抖动）。第二行放耗时条（3pt，v2 以耗时作为星级主轴）。

为什么分数放最右 拇指从底部向上扫时，视觉落点是「中→右」。把资源（剩余发射）放中、把成就（分数）放右， 符合「先看我还剩什么，再看我赚了多少」的读序。

4.4 首次引导（FTUE）

第 1 关强制 3 步手指引导，用半透明遮罩 + 挖孔：

  1. 手指图标落在空白区 + 文案「拖空白拉方向·松手发射」（v2 无方向虚线，实时预测点列自动显示）
  2. 松手后球飞行，追上球画箭头「碰墙壁会反弹」
  3. 球落回时手指图标落在横条上「拖横条接住→向左拖向左回弹」（接住 → 金色飘字 + 回弹音效；v2 核心教学）
关键引导不做成"点下一页"的轮播，必须在真实局内边玩边学。 第 3 步如果玩家没接住，引导不推进（v2 接住回弹就是主玩法本身，接不住就体会不到连续链的爽感）。

05动效与转场

场景动效时长 / 曲线说明
启动 → 首页标题从 scale 0.86 弹入，方块条逐个错峰落下420ms / easeOutBack建立“弹”的品牌调性
首页 → 游戏卡片式放大转场（首页微缩预览区 → 全屏容器）300ms / easeOutCubic空间连续，避免硬切
方块入场逐行逐列错峰 scale 0.4→1每块 260ms，行错 60ms / 列错 20ms已在原型实现；同时让玩家预读布局
方块消除先闪白 60ms → 再碎裂白闪 60 / 碎裂 400ms白闪是"命中确认"，碎裂是"结果"，两段比一段清晰得多
墙壁命中整块 3% 缩放脉冲 + 白色高光 90ms90ms / easeOut已实现（cell.flash）；让玩家确认"是墙，不是没打中"
分裂青色光环扩散 + 屏幕震动 3.5 + 两球分飞400ms全程最强反馈，是产品的"招牌时刻"
穿缺口缺口处闪光环 + 短暂 0.15× 慢放120msP1 强调"进来了"，帮助建立空间感
接住球横条压扁 scaleY 0.7 回弹 + 金色粒子180ms"接住了"的物理感
漏接红色粒子上浮 + 屏幕震动 4 + 漏接线闪300ms负反馈明显但不punishing
通关全场剩余方块同时碎裂 → 星星逐颗 scale 0→1.25→1每颗 260ms，间隔 180ms星星必须逐颗，一次性出现会砍掉 60% 的爽感
失败容器整体 translateY 3px 抖动 + 变暗240ms不要黑屏淡出，那会放大挫败
结算浮层遮罩淡入 + 面板 translateY 24→0260ms / easeOutBack浮层出现时立即停止音效 ducking 恢复
统一时序原则 ① 所有游戏内动效不得阻塞输入——玩家随时可以重新拖横条摆位/拉回弹方向，动效只是"锦上添花"； ② 结算浮层的按钮延迟 400ms 才可点（防止误触跳过分数动画），但点屏幕任意处可加速； ③ 曲线只用两条：easeOutBack（入场，带弹性）与 easeOutCubic（退场/位移）， 不要为了"丰富"混用一堆曲线，那会让手感显得廉价。

07落地注意事项

事项要求为什么
主题色一致性所有色值从 config.js 的 PALETTE 取，禁止在渲染代码里硬写十六进制原型阶段已经出现同一红色在 3 处略有差异的情况，正式版必须单一来源
等宽数字分数、倒计时、角度一律用等宽数字或手动 letterSpacing分数从 999→1000 时字宽变化会让 HUD 抖动
安全区HUD 下移 safeArea.top；漏接线与提示文字上提避开 Home IndicatoriPhone 刘海 / 安卓挖孔会遮挡 HUD；底部手势区会误触
横条可点区视觉高 12pt，触摸热区扩到 32pt（上下各 10）12pt 远低于拇指最小可点尺寸（≈ 44pt），玩家会"抓不住横条"
弹道预测点列可关闭设置里提供开关（原型已实现 showAim）；v2 默认只保留点列，方向虚线已删对硬核玩家它削弱挑战；对低端机它省 1800 次模拟
色彩不可作为唯一信息「可入缺口 / 撞墙壁」除颜色外必须有 ✕ 图标 + 文案（原型已实现）色觉障碍与户外强光下只靠颜色会失效
方块形状区分分裂块除了青色还要有 ✦ 符号，墙壁除了灰色还要有 描边 + 高光纹理同上，冗余编码（颜色 + 形状）才鲁棒
低端机降级三级开关：拖尾 → 同屏球上限 16→12 → 粒子上限 200→80 → 锁 30fpsv2 实测平衡仿真峰值 4.3 球/屏（分裂链），但压测上限 16，低端机需预留余量
浮层也画在 Canvas结算 / 暂停浮层不用 DOM（小游戏无 DOM），按本稿样式程序绘制原型已按此实现，直接复用即可
分享卡片文案「我在第 12 关拿了 3 星，你能打过吗？」+ 截图带上具体关卡与星级的分享点击率显著高于通用文案
本稿与原型的关系 本稿的所有尺寸、间距、色值都对应 design/js/prototype-data.js 与 prototype-render.js 的实际配置， 不是凭空画的图。建议流程：先在 prototype.html 里调好手感和数值 → 再把配色/字号搬到本稿 → 美术按本稿出图。
